How to read these

Each frame is the XWork window at 1280 × 800, drawn with the tokens of 00-Design.md. Frames are static HTML + CSS with no script; overlays (dialogs, menus, popovers) are drawn in place. Hover states are not documented, following the design system. Fonts load from Google Fonts as the documented substitutes (Cormorant Garamond for Copernicus, Inter for StyreneB, JetBrains Mono for code); offline they fall back to system serif / sans / mono.

Frame ids follow 03-FunctionalRequirements.md §19; letters (a, b, c…) split one requirement into several states. FE-NNN documents should reference a frame as 01-Wireframe/04-Projects.html#new-session.

Rule: raw text the user did not write (source code, Markdown source of a project file, terminal output) sits on a dark surface. Rendered text and the user’s own notes sit on cream. Edit / Preview of one project file flips between the two.
