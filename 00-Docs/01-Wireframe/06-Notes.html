Notes

Notes are the user’s own writing, so they stay on the cream surface in both modes (unlike project Markdown files, whose raw source is dark). Two columns: list with search, filters, Archive and Trash on the left; the editor or preview of the selected note on the right. Content autosaves.

ConPTY quirks on Windows

Resize

Resize must be debounced (~50 ms) or ConPTY drops frames when four panes resize at once. The first frame after a burst is the one that counts.

  • portable-pty resize is sync — call it off the async worker
  • Claude Code redraws the whole alternate screen on SIGWINCH, Codex only the prompt line
  • Ghostty core handles the reflow; WTerm just needs the final size

Input

Vietnamese IME composes in the WebView, not in the PTY. Send the committed string only; never forward composition events as key presses.

Test matrix: Codex, Claude, pwsh, alternate screen, mouse mode, synchronized output, emoji, Telex IME, paste, resize.

Quick Note floating window
