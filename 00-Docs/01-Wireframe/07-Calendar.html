Wireframes · §19.6 · FE-021, FE-022, FE-010

Calendar

Month grid as the main view with a 360 px side panel that switches between the selected day, Upcoming and Missed. Today is the ink circle; the selected day is the cream-strong cell. Events linked to a project carry a small ink dot; all-day events are solid cream-strong chips.

Index·App shell·Home·Projects & sessions·Files·Notes·Calendar
19.6.1

Month view with the day panel

Clicking a day selects it, updates the panel and offers New event this day with the date prefilled. Clicking an event opens the detail popover (19.6.5).
