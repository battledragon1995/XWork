Wireframes · §19.4 · FE-016, FE-017, FE-018

Files

Phase 2 adds a secondary File Explorer beside the tab/pane area, a read-only source viewer and a Markdown editor. Rule of surfaces: raw text (source, Markdown source) is a dark pane; rendered Markdown is a cream page. The two modes of one file flip between them.

19.4.1

Session with File Explorer open

Toggled from the tab bar (Ctrl B). Filter, refresh, collapse-all at the top; the tree follows ignore rules. The context menu shows every file action: open in tab / empty pane / split, copy paths, reveal in the OS. No create, rename, move or delete.

//! PTY lifecycle for one pane. Windows uses ConPTY, macOS the system PTY. use portable_pty::{CommandBuilder, PtySize, native_pty_system}; use tokio::sync::mpsc; /// Minimum gap between two resize calls forwarded to the PTY. const RESIZE_DEBOUNCE: Duration = Duration::from_millis(50); pub struct PtyHandle { master: Box<dyn MasterPty + Send>, child: Box<dyn Child + Send>, last_resize: Instant, } impl PtyHandle { /// Spawns `profile` at the project root with its own environment. pub fn spawn(profile: &CliProfile, cwd: &Path, size: PtySize) -> Result<Self> { let pair = native_pty_system().openpty(size)?; let mut cmd = CommandBuilder::new(&profile.command); cmd.args(&profile.args); // never joined into a shell string cmd.cwd(cwd); for (k, v) in profile.env() { cmd.env(k, v); } let child = pair.slave.spawn_command(cmd)?; Ok(Self { master: pair.master, child, last_resize: Instant::now() }) } /// Forwards a resize, dropping bursts closer than RESIZE_DEBOUNCE. pub fn resize(&mut self, size: PtySize) -> Result<()> { if self.last_resize.elapsed() < RESIZE_DEBOUNCE { return Ok(()); } self.last_resize = Instant::now(); self.master.resize(size) } }

XWork

Local-first desktop workspace for many projects and many AI CLIs. Runs on Windows and macOS. No account, no cloud.

Why

  • One window per machine, one workspace per project
  • Codex, Claude and a plain terminal side by side, up to four panes per tab
  • Notes and reminders that live next to the work, not in another app

Status

PhaseScopeState
1Projects, sessions, terminal, panesin progress
2File explorer, source viewer, Markdownplanned

Development

pnpm install
pnpm tauri dev
Terminal behaviour is verified on Windows first; macOS at release time.

See the docs for requirements and structure.
